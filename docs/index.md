## Wo finde ich was?

| Ich will … | Hier steht es |
|---|---|
| eine Bedingung oder eine Wiederholung schreiben | [Verzweigung](grundlagen/verzweigung.md), [Schleifen](grundlagen/schleifen.md) |
| mit Text, Datum und Uhrzeit oder Zufallszahlen arbeiten | [String](grundlagen/string.md), [Datum und Zeit](grundlagen/datum_zeit.md), [Zufall](grundlagen/zufall.md) |
| feste Auswahlwerte festlegen oder Werte über einen Schlüssel finden | [Enum](grundlagen/enum.md), [Dictionary](grundlagen/dictionary.md) |
| Fehler abfangen, statt das Programm abstürzen zu lassen | [Exception Handling](grundlagen/exceptions.md) |
| eigene Klassen entwerfen | [Objektorientierung](oop/index.md) |
| Daten in einer Datei speichern oder einlesen | [Dateien](grundlagen/dateien.md), [Serialisierung (JSON, XML)](serialisierung/index.md) |
| Daten in einer Datenbank ablegen und abfragen | [Datenbank (MySQL)](db/index.md) |
| eine Oberfläche bauen | [Oberflächen mit WPF](ui/index.md) |
| einen Ablauf aufschreiben, bevor ich ihn programmiere | [Pseudocode und Struktogramm](methoden/algorithmen/pseudocode_struktogramm.md), [Aktivitätsdiagramm](methoden/uml/aktivitaetsdiagramm.md) |
| festhalten, wer ein System wofür benutzt und woraus es besteht | [Use-Case-Diagramm](methoden/uml/usecase_diagramm.md), [Klassendiagramm](methoden/uml/klassendiagramm.md) |
| prüfen, ob ein Ablauf richtig rechnet und keinen Fall vergisst | [Schreibtischtest](methoden/testen/schreibtischtest.md), [Entscheidungstabelle](methoden/algorithmen/entscheidungstabelle.md) |
| ein Projekt planen | [Phasenkonzept](methoden/projekt/phasenkonzept.md), [Lastenheft und Pflichtenheft](methoden/projekt/lastenheft_pflichtenheft.md), [Vorgehensmodelle](methoden/projekt/vorgehensmodelle_klassisch.md) |
| meinen Code versionieren und mit anderen teilen | [Git](git/bestehendes_projekt.md) |
| wissen, wie Code bei uns aussehen soll | [Coding Conventions C#](grundlagen/coding_convention_cs.md) |
